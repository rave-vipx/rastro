Connect an export

Supported: JSON files or databases saved by Rastro.

Load the records of your own export into a project's dataset with rastro.load_records. They are validated like a web load, keep their provenance and show as an imported snapshot. Then open the project here.

from rastro import load_records

load_records("pages/events.toml", records, source_url="https://example.com/events")

For a database saved by Rastro, turn on Advanced to see how to point a project at it.

Fix a site

      
When a site changes, Rastro proposes a new way to read it and checks it. Compare the fields, then apply it with a reason or discard it.

      
Fixes need past versions saved in this project. Turn that on when you create a scraper, or ask for it with Advanced on.

      

        
        
        
      

      

      

      

    

    

      
Apply fixes automatically

      
      
Off by default. If you turn it on, Rastro applies a fix only when it passes every check and the semantic judge (a configured model) agrees the values kept their meaning; otherwise it waits for you here. Off means you apply fixes yourself, with a reason.

      Browser and stealth
      
Whether a site uses a browser is part of the project; turn on Advanced to see where. Stealth is never saved in a project or a bundle: it is a grant for this Studio session only.

      
      
Off by default. Lets jobs that ask for render = "stealth" run while this Studio is open. Nothing is written to a job or a bundle.

    


    

      Network permissions
      
Studio reads only the hosts the job allows (allowed_hosts under [acquisition]); robots.txt and public-address checks always apply. Operator grants are flags of the command that starts Studio, never settings here:

      
rastro studio --allow-egress
rastro studio --allow-env NAME
rastro studio --allow-stealth
